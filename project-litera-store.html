Litera Store

E-Commerce Book Website - Platform Belanja Buku Online Modern

2024
E-Commerce
HTML, CSS, JavaScript

Tentang Project

Litera Store adalah platform e-commerce yang dirancang khusus untuk penjualan buku online. Website ini menyediakan pengalaman berbelanja buku yang modern dan user-friendly, memudahkan pengguna untuk mencari, menelusuri, dan membeli buku favorit mereka.

Fitur Utama

  • Katalog Buku Lengkap

    Sistem katalog yang terorganisir dengan kategori dan filter pencarian

  • Shopping Cart

    Keranjang belanja interaktif dengan update real-time

  • Detail Produk

    Informasi lengkap setiap buku termasuk deskripsi, penulis, dan review

  • Responsive Design

    Tampilan optimal di semua perangkat (desktop, tablet, mobile)

  • User Authentication

    Sistem login dan registrasi untuk pengguna

  • Search & Filter

    Pencarian cepat dengan filter berdasarkan kategori, harga, dan rating

Teknologi yang Digunakan

HTML5
CSS3
JavaScript
Local Storage

Tantangan & Solusi

Tantangan

Membuat sistem keranjang belanja yang persistent tanpa backend

Solusi

Menggunakan Local Storage untuk menyimpan data keranjang belanja, sehingga data tetap tersimpan meskipun halaman di-refresh

Tantangan

Membuat tampilan yang menarik dan responsif di semua perangkat

Solusi

Menggunakan CSS Grid dan Flexbox dengan pendekatan mobile-first design

Hasil & Pembelajaran

Melalui project ini, saya berhasil mengembangkan pemahaman yang lebih dalam tentang:

  • Manipulasi DOM dengan JavaScript
  • Penggunaan Local Storage untuk data persistence
  • Implementasi responsive design dengan CSS
  • Pengelolaan state aplikasi tanpa framework
  • User experience design untuk e-commerce
